# ROCKNIX Controller Plus

**Retroid Pocket 5上のROCKNIX**に、コントローラー、タッチスクリーン、マウス、トラックボールの拡張機能を追加します。

[English documentation](README.md)

> [!WARNING]
> このパッケージは現在、Retroid Pocket 5専用です。インストーラーは機種を確認し、未対応の機器では変更を加えずに終了します。

## 機能

- EmulationStationが対応する全プラットフォームでのゲーム別ボタンマッピング
- A、B、X、Y、L1、L2、R1、R2の個別設定
- 各ボタンに`NORMAL`、`TURBO`、`REPEAT`、`TOGGLE`を設定可能
- 1つの物理ボタンを別のボタン、または対応する全ボタンへ割り当て
- TURBOとREPEATの速度設定
- 斜め入力を禁止するゲーム別4-way十字キーモード
- アナログ入力を標準とし、ゲームごとに左スティックの十字キー変換を選択可能
- HOME＋戻るボタンで開くゲーム内設定OSD
- アーケード向けのタッチスクリーン、相対移動マウス、慣性付きトラックボールモード
- マウス移動量とトラックボール慣性の調整
- 回転したアーケードゲームに合わせたポインター移動方向の自動補正
- 充電中の自動スリープを防ぎ、ネットワークおよびSSH接続を維持
- ユーザー空間の仮想ゲームパッドへ置き換えない、InputPlumberネイティブ統合
- ROCKNIXのPortsメニューから直接実行できるインストーラーとアンインストーラー

## 必要環境

- Retroid Pocket 5
- 標準のEmulationStationおよびInputPlumberサービスを備えた新しいバージョンのROCKNIX
- ストレージカードをPCへ接続するか、ネットワーク経由でROCKNIXの`STORAGE`領域へファイルをコピーできる環境

## インストール

### 方法1：リポジトリのフォルダをコピーする

1. このリポジトリを **Code → Download ZIP** からダウンロードし、展開します。
2. 収録されている`roms`フォルダを、ROCKNIXの`STORAGE`領域のルートへコピーします。
3. 確認が表示された場合は、既存の`roms`フォルダへ統合してください。既存のROMは削除しないでください。
4. ストレージカードをRetroid Pocket 5へ戻し、ROCKNIXを起動します。
5. 新しい項目がすぐに表示されない場合は、ゲームリストを更新するかEmulationStationを再起動します。
6. **Ports**を開き、**Install Retroid Controls**を実行します。
7. `INSTALLATION COMPLETE`と表示されるまで待ちます。ネイティブ入力ドライバーを有効にするため、約8秒後に本体が自動再起動します。

コピー後の主要なファイル配置は次のようになります。

```text
STORAGE/
└── roms/
    └── ports/
        ├── Install Retroid Controls.sh
        ├── Uninstall Retroid Controls.sh
        └── rocknix-retroid-controls/
```

### 方法2：配布アーカイブを使用する

1. [`retroid-controls-final.tgz`](retroid-controls-final.tgz)をダウンロードします。
2. 内容を`STORAGE/roms/ports/`へ直接展開します。
3. 上記の手順4〜7を実行します。

自動再起動を中断しないでください。中断してしまった場合は、コントローラーを確認する前に通常の方法で本体を一度完全に再起動してください。

## ゲーム別設定の使い方

EmulationStationで次の操作を行います。

1. ゲームを選択します。
2. ゲームの詳細設定またはゲーム別オプションを開きます。
3. 必要なコントローラー項目だけを変更します。
4. 通常どおりゲームを起動します。

設定はゲームごとに保存されます。変更していない項目は標準動作のままです。ボタンマッピング、TURBO、REPEAT、TOGGLE、4-wayモード、左スティックモードは全プラットフォームで使用できます。タッチ、マウス、トラックボールの設定は、対応するアーケードコアに追加されます。

### ボタンモード

| モード | 動作 |
|---|---|
| `NORMAL` | 物理ボタンを押している間、選択した対象ボタンを入力します。通常のボタン変更に使用します。 |
| `TURBO` | 物理ボタンを押している間、対象ボタンを連射します。 |
| `REPEAT` | 最初の入力後に設定された時間だけ待ち、キーボードのキーリピートのように入力を繰り返します。 |
| `TOGGLE` | 物理ボタンを押すたびに、対象ボタンの押しっぱなしと解放を切り替えます。 |
| `Disabled` | 物理ボタンからゲームへの入力を無効にします。 |

各物理ボタンの割り当て先として、A、B、X、Y、L1、L2、R1、R2、または対応する全ボタンを選択できます。

### 方向入力とアナログ設定

- **8-way：** 斜めを含む通常の十字キー動作です。
- **4-way：** 同時に1つの軸だけを有効にし、4方向入力用ゲームへの斜め入力を防ぎます。
- **Native analog：** 左アナログスティックをアナログ入力としてそのまま渡します。これが標準設定で、スペースハリアーなどのゲームに推奨します。
- **Left stick as D-pad：** 左アナログスティックをデジタル方向入力へ変換します。

### アーケードのタッチ操作モード

- **Touchscreen：** 画面位置を直接指定するタッチ入力です。
- **Mouse：** ノートPCのトラックパッドのような相対移動ポインターです。
- **Trackball：** 慣性を調整できる相対移動入力です。

マウス移動量は10%から200%まで、10%刻みで変更できます。ポインターの移動方向は、アーケードゲームの画面回転へ自動的に追従します。

## ゲーム内OSD

ゲームの実行中に次の操作を行います。

1. **HOME**を押したままにします。
2. **戻るボタン**を押します。
3. 両方のボタンを離します。

ゲームが一時的にフルスクリーンを解除し、`RETROID CONTROLS`メニューが表示されます。

- 十字キー：項目の移動
- A：決定
- B：戻る、または閉じる

OSDは連射のない専用入力プロファイルを使用するため、ゲーム側のTURBOやREPEAT設定はメニュー操作へ影響しません。メニューを閉じると、フルスクリーン表示とゲーム用入力プロファイルが復元されます。変更内容は現在のゲーム用として保存されます。コントローラー設定はOSDを閉じた時点で反映され、タッチ、マウス、トラックボールのモード変更は次回のゲーム起動時に反映されます。

## 充電とスリープ

外部電源へ接続している間は自動スリープを抑止し、ネットワーク接続を維持します。電源ボタンを意図的に押した場合は、通常どおりスリープできます。

## 更新と再インストール

`STORAGE/roms/ports/`内のファイルを新しいパッケージで置き換え、**Install Retroid Controls**をもう一度実行します。設定の適用処理は繰り返し実行できる設計で、メニュー項目を重複して追加しません。

設定ファイルを変更する前に、インストーラーは次の場所へ日時付きバックアップを作成します。

```text
/storage/.config/retroid-controls/backups/
```

## アンインストール

1. **Ports**を開きます。
2. **Uninstall Retroid Controls**を実行します。
3. `UNINSTALLATION COMPLETE`と表示され、自動再起動するまで待ちます。

アンインストーラーは、このパッケージが追加したコントローラー、タッチスクリーン、Sway、電源、EmulationStationの設定を削除します。後から再インストールできるように、Ports内のインストーラーファイルは残します。

アンインストール直前の設定は、次の場所へ保存されます。

```text
/storage/.config/retroid-controls/uninstall-backups/
```

## トラブルシューティング

### Portsにインストーラーが表示されない

`Install Retroid Controls.sh`が`STORAGE/roms/ports/`の直下にあることを確認し、EmulationStationのゲームリストを更新するかROCKNIXを再起動してください。

### インストール後にコントローラーが反応しない

カスタムInputPlumberバイナリと機能マップは、本体の完全な再起動時に有効になります。インストーラーが行う自動再起動の完了を待ってください。中断した場合は本体を通常どおり一度再起動してください。ゲームの実行中にInputPlumberを繰り返し再起動しないでください。

### HOME＋戻るボタンでOSDが開かない

インストールと再起動の完了後、EmulationStationからゲームを起動してください。HOMEと戻るボタンを同時に押し、両方を離します。HOMEホットキーが押しっぱなしになるのを防ぐため、OSDは両方のボタンが離されるまで待ってから開きます。

### インストールまたはアンインストールに失敗する

次のログを確認してください。

```text
/storage/retroid-controls-install.log
/storage/retroid-controls-uninstall.log
```

スクリプトは検証エラーが発生すると処理を停止し、復旧用として設定ファイルの日時付きバックアップを残します。

## パッケージ構成

```text
roms/ports/
├── Install Retroid Controls.sh
├── Uninstall Retroid Controls.sh
└── rocknix-retroid-controls/
    ├── install.sh
    ├── uninstall.sh
    └── payload/
```

`payload`フォルダには、RP5用InputPlumberバイナリ、コントローラープロファイル、OSD、タッチスクリーン用ヘルパー、サービス定義、重複適用を防ぐ設定変更ツールが収録されています。
